# Adcom

Centro de informes y diagnósticos de Adcom.

## Contenido

- `index.html`: página principal de informes.
- `clientes.html`: hub de informes de clientes.
- `diagnostico-educacion.html`: diagnóstico del sector de educación superior.
- `astrobet-creyentes-2026.html`: informe de la campaña Creyentes de Astrobet.

## Uso local

Abre `index.html` en un navegador para acceder al contenido.

## Convención de nombres

Los archivos de contenido usan `kebab-case`. Los documentos estándar de GitHub conservan sus nombres convencionales, por ejemplo `README.md`.
